# 10 — Entrega final

**Objetivo:** fechar a `mini-clinica` como um projeto apresentável e explicar como ela funciona.

## Entrega

1. README na raiz do seu repositório com:
   - o que o app faz
   - como rodar: subir a API fake (`cd api && npm install && npm start`) e depois o app (`cd mini-clinica && npm install && npm run dev`)
   - como rodar os testes
2. Apresentação de até 15 minutos pro mentor, seguindo uma ação de ponta a ponta. Por exemplo, excluir um paciente:
   - o clique na página
   - o hook
   - o service
   - a instância do axios
   - a requisição na aba Network
   - o toast vindo do store

## Critérios de aceite

- [ ] `npm run build` sem erros
- [ ] `npm run lint` sem erros
- [ ] `npx vitest run` passa
- [ ] Um colega consegue rodar o projeto só seguindo o README
- [ ] Explica cada camada apontando o arquivo, sem ajuda
