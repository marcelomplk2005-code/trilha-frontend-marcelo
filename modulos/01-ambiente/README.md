# 01 — Ambiente de trabalho

**Objetivo:** clonar, commitar, abrir PR e usar o DevTools sem travar.

## Conceitos

- Terminal básico
- Git: `clone`, `branch`, `add`, `commit`, `push`
- Pull Request
- Node **22.12 ou mais novo** e npm (a API fake do módulo 06 exige essa versão)
- VS Code com as extensões ESLint e Prettier
- DevTools: abas Elements, Console e Network

## Recursos

- [Learn Git Branching (PT-BR, interativo)](https://learngitbranching.js.org/?locale=pt_BR)
- [GitHub — Olá, Mundo (PT-BR)](https://docs.github.com/pt/get-started/start-your-journey/hello-world)
- [Chrome DevTools — visão geral](https://developer.chrome.com/docs/devtools/overview)

## Entrega

Repositório `trilha-frontend-<seu-nome>` com um README (seu nome e o objetivo da trilha), enviado por PR a partir de uma branch.

## Critérios de aceite

- [ ] `node -v` mostra 22.12 ou mais novo
- [ ] PR com pelo menos 2 commits de mensagem descritiva
- [ ] PR aprovado e mergeado pelo mentor
- [ ] Mostra ao mentor uma requisição qualquer na aba Network do DevTools
